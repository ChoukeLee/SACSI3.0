# 撤销在住日租优惠

日租优惠调整过去在页面和数据库同时拒绝 0，导致无法恢复原价。本修改让在住订单的优惠金额可以明确设为 0，并显示“撤销优惠，恢复原价”。空白、负数和页面中的小数仍不可提交。

沿用本人登录的 `applyDiscount` / `daily_apply_discount_rpc` 业务入口，原子更新优惠、最终应收及已有应收；记录优惠及最终应收的更正前后审计。数据库保留原角色检查并核对房源项目范围。收款、账本、住期、日价、房态和保洁不改。仅接受在住订单；已退房订单继续使用原更正流程。

## 发布与办理

1. 审核变更后先发布迁移 `20261126091800_daily_discount_clear.sql`，再发布前端。业务数据通过本人登录的业务入口修改。
2. 办理前重新核对选中订单的住期、原价、优惠和已收，避免覆盖其他人的修改。
3. 在“优惠调整”中明确输入 0，填写撤销原因并提交。结果未知时先查回，不自动重复提交。
4. 核验优惠归零、最终应收恢复原价，并核对收款、住期、日价、房态和保洁未改变。

## 本地验证

- 28 项相关页面测试通过，包括显式 0 能提交、空白/负数/小数不能提交。
- 66 项原生数据库测试通过（9 项新增、57 项已有），包括恢复应收、保留已有付款与房态、审计前后值、拒绝越权/非在住/越界金额及空原因。
- TypeScript、变更文件 ESLint、格式、日租规则和 Next.js 生产构建通过。

本地测试和构建不代表生产发布或本笔业务已撤销。
