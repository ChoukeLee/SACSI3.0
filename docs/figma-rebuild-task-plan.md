# SACSI Figma Rebuild Task Plan

## 目标

这份任务清单用于跟踪 Figma 重构从设计到代码落地的全过程。每一项都应该能被明确验收。

## 阶段 A：设计准备

### A1. 确认重构边界

状态：待开始

任务：

- 确认本次允许抛开旧 `DESIGN.md` 的视觉规则。
- 确认业务逻辑、数据库、财务同步、审计日志不变。
- 确认第一批页面范围。

验收：

- `figma-ui-rebuild-brief.md` 被确认可作为总方向。

### A2. 创建 Figma 文件

状态：待开始

任务：

- 创建 `SACSI 3.0 UI Rebuild` Figma 文件。
- 创建页面：`00 Foundations`、`01 Components`、`02 App Shell`、`03 Daily Rentals`、`04 Contracts`、`05 Finance + Records`、`06 Mobile`、`99 Archive`。

验收：

- Figma 文件结构完整。
- 文件链接记录到项目文档。

### A3. 准备真实业务样本

状态：待开始

任务：

- 日租样本：入住、预订、未付款、已付款、待清洁、维修、非固定离店。
- 长租样本：正常、生效、资料待补、15天内应缴、待收未逾期、逾期。
- 出售样本：已售、待回款、逾期回款、已过户、占位出售。
- 财务样本：应收、已收、部分收款、逾期、取消、手工调整。
- 房源样本：11#普通公寓、5#大平层、8楼自用办公室、已售、空闲、维修。

验收：

- 每个核心页面都有真实数据驱动的设计样例。

## 阶段 B：Figma Foundations

### B1. 字体和字号

状态：待开始

任务：

- 定义页面标题、区块标题、卡片标题、正文、表格、辅助文字、金额数字。
- 确认中文和法语字体表现。

验收：

- 同一层级在所有页面使用同一字号和字重。
- 金额、日期、房号数字稳定。

### B2. 色彩系统

状态：待开始

任务：

- 定义背景色、卡片色、边框色、主操作色。
- 定义财务状态色：已收、未收、逾期、部分收款。
- 定义房源状态色：空闲、日租、预订、长租、出售、待清洁、维修、自用。

验收：

- 财务颜色和房源颜色不会互相混淆。
- 0 欠款不会被设计成风险状态。

### B3. 间距、圆角、阴影

状态：待开始

任务：

- 定义页面边距。
- 定义卡片、表格、按钮、输入框、抽屉圆角。
- 定义普通卡片、浮层、抽屉阴影。

验收：

- 页面不臃肿。
- 工具栏不比业务主区域更显眼。
- 抽屉贴合页面边界。

## 阶段 F：上线验收

### F1. 视觉验收

状态：待开始

检查：

- 主要页面是否像同一个产品。
- 按钮、表格、卡片、抽屉是否统一。
- 页面是否仍然能高密度工作。

### F2. 业务验收

状态：待开始

检查：

- 日租创建、入住、退房、续住、收款。
- 长租收款、续租、退租。
- 出售收款、过户。
- 财务应收和流水。
- 审计日志。

### F3. 技术验收

状态：待开始

检查：

- `npm run typecheck`
- `npm run build`
- 主要页面手动访问。
- 关键按钮响应速度。
- 不跳顶。
- 不出现旧缓存账务。

## 第一轮建议范围

第一轮不要超过以下范围：

1. Foundations
2. 第一批组件库
3. 日租业务页
4. 长租合同页
5. 出售合同页

第一轮通过后，再进入房源、财务、客户。
