# AI 助手命令入口需求记录

## 背景

当前后台顶部已有全局搜索框。希望参考桌面 `MG/mg-menu` 中 WhatsApp AI 助手的“自然语言理解 + 受控工具执行”方式，将搜索框升级为后台 AI 助手入口。

## 目标

用户可以通过自然语言在后台查询或修改业务数据，例如入住、退房、收租、押金、清洁任务、房态和合同信息。

## 第一版范围

1. 查询房间状态、客户、合同、应收和收款记录。
2. 创建或更新日租入住信息。
3. 办理日租退房。
4. 记录收租、补款和押金。
5. 创建或完成清洁任务。

## 安全原则

AI 不直接写数据库。AI 只能生成操作草稿，并调用后端暴露的受控工具。涉及修改数据的操作必须先展示确认摘要，用户确认后才执行。

## 推荐交互

用户输入：

```text
602 收到租金150万，6月8日交付
```

系统回复：

```text
我准备执行：
房间：602
操作：记录长租租金
金额：1,500,000 XOF
收款日期：2026-06-08

是否确认？
```

确认后再写入 `payments`、`receivables`、`ledger_entries` 和 `audit_logs`。
