## 手术边界

1. **权限查询按语句复用。** 保留 RLS、原 helper、角色、ACL、策略命令及 permissive/restrictive 组合。固定角色检查用 InitPlan；子表在同一 SQL 语句复用 RLS 可见的项目、楼栋、房源和出售合同 ID 集合。保留所有 NULL 条件和楼栋/房源同时授权检查，不新增 definer，不跨请求缓存权限。
2. **项目自身原策略保持。** 原生对照发现直接内联项目 `access_mode` 会改变 UPDATE 新行检查语义，因此没有采用。完整父策略签名及 RLS 状态有漂移时，新迁移直接拒绝，未来改变父权限必须复核子表及 helper 等价性。
3. **日历读取与全量财务分开。** 初次仅所选楼栋及可见窗口，移动日期/楼栋重新读取。额外保留全楼栋当前入住、未结束预订、全部历史未结、当月实际退房、当月收款引用、未完成保洁及这些订单的完整付款历史；全月现金沿用独立严格读模型，不用窗口明细代算。
4. **客户端只展开可见日期。** 跨月/跨窗住宿仍显示，移动端与桌面共用受授权窗口；读取失败显示未知、禁旧状态办理；防请求竞态及返回初始窗口时复用过期 SSR 数据。没有按最近 N 条截断历史、导出或汇总。
5. **导航跟随真实过渡。** 关闭侧栏/底栏及首页业务入口的 Next 内建自动预取；等待不再在 3 秒后假结束，去重同一目标点击，不直接删除 React 管理节点，旧页等待时阻止鼠标及键盘操作。
6. **投影不得丢业务证据。** 长租付款保留支付方式、请求类型及原冲正关联字段；实际 loader 到现金分类模型回归确保抵扣与未核冲正不能被当成经营现金。

这不是全站服务端分页完成声明：合同、档案与报表仍有完整历史读取；本轮优先移除其共用权限成本。后续若实测显示载荷仍是主要瓶颈，再按页面划分摘要/分页/详情，不以局部明细计算总账。

保留的独立问题：middleware 与页面的远程 Auth 校验尚未去重；未证明它是本轮主要耗时，不为省一次请求削弱身份核验。长租 loader 还有 `SACSI7-STOREFRONT` 的历史虚拟启用/价格补丁，需按真实业务配置单独处理，不在性能手术中擅自改变可租规则或价格。
