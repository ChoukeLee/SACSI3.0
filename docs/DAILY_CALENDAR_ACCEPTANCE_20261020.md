## 本批范围

经样板确认，恢复房间×日期日历为默认操作方式，使用当前工作台样式。压缩标题、工具栏和普通房间行；桌面 7/14 天、手机 3 天，房号/日期冻结，按数据库真实楼层分组。默认无详情占栏；选择后才展开，关闭或 Escape 返回原触发点。
