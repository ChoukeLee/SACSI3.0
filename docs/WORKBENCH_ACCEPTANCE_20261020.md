# 待办、审计与全站技术验收 · 2026-10-20

## 范围与验收口径

本批补齐个人业务待办、操作审计、手机导航及主要中法页面统一核验。它不包含重新设计尚未确定的退款规则、自动生成下期应收、扩大账号权限或历史身份回填。数据质量页面用于查询与受控修复，不会在浏览器验收时自动修复历史问题。

| 范围 | 验收标准 |
| --- | --- |
| 本人待办 | 当前认证账号与现有业务/项目权限；完整范围状态统计、30 条分页；完成优先于过期；未知状态不执行；旧 RPC 兼容 |
| 本人确认 | 中法四类详情与原 POST/请求号一致；不自动确认、不批量批准；网络未知沿用原单，不换号重录 |
| 审计 | 管理员/老板权限不变；列表轻量、完整计数、独立精确 ID 详情；撤权后不再显示旧异步结果 |
| 审计事实 | 真实结果金额及币种、核销和覆盖前后；录入账号不代认实际收款人；缺失仍未知；当前目录名称只作补充 |
| 完整导出 | 同一筛选完整读取，固定安全字段及 CSV 公式注入防护；超过 100,000 条明确拒绝，不静默截断 |
| 筛选恢复 | SSR 读取失败保留合法筛选与页码；后退/前进不吞重复参数；中法路径保留查询上下文 |
| 手机与导航 | 320/390 像素检查；菜单在桌面收起后仍可打开；底部导航按角色显示；长租/维护/质量不遮挡手机 |

## 技术核验与证据

本批最终本地核验：普通测试 3,017 通过 / 1 条条件跳过，239 个文件通过；原生 PostgreSQL 453 通过 / 1 条条件跳过，30 个文件通过。lint、421 份治理文件格式、日租规则、TypeScript、生产构建及 diff 检查通过。原生条件项为未显式启用的本地 CLI 顾问检查；生产安全顾问另行实际核对，不能把跳过写成通过。

真实管理员会话完成 38 个不同页面/宽度检查：12 个主要页面的中文 390px、法语 320px、中文 1280px，以及 CIMAC 首页和长租范围。最终均有真实页面内容、无可见读取错误及未受控横向溢出，截图分项保存。部分本地请求曾超过首次等待，后续确认已加载完成；本机到 Auth 的观测有 0.15 秒至 28.58 秒波动，质量页也需等待完整检查。这是功能/布局验收，不是“全站秒开”或性能 SLA。

自动化检查使用合成身份/本地一次性 PostgreSQL，不连接生产库写入。全站页面入口角色矩阵覆盖 5 类角色及未登录请求，页面保护、数据库 RLS、接口授权分别验证，不用隐藏按钮代替授权。

浏览器只读检查主要页面：首页、长租、出售、财务、资产、日租、客户、报表、本人待办、维护、审计和数据质量；检查中法、窄屏、可见错误、导航与查询。SACSI/CIMAC 的适用项目范围另查，不把 CIMAC 显示为出售或日租业务。

当前最终发布证据保存在本机忽略目录 `work/workbench-acceptance-20261020/`：逐页记录、实际截图、迁移前后业务表行哈希、备份校验及最终提交/CI/生产部署。只有对应提交的 CI 成功、生产 Ready 和实际页面检查齐全后，才将本批作为已发布交付；Git push 本身不代表上线成功。

## 数据与发布保护

- 新迁移仅增加只读函数及审计时间/ID 索引，旧个人确认 RPC 与写入契约保留。公开读入口为 invoker；私有待办读取在数据库内重新检查当前身份与授权。
- 真实数据核验发现旧日租/组合收款的轻量列表遗漏金额，已用独立前向兼容迁移恢复原金额和必要的三个计划标量；原已发布 SQL 未改写。列表/详情金额相同，CSV 末列追加记录金额，原币不换算，旧列顺序不变。
- 发布前生成本地加密应用表快照并解密哈希核验，密钥分目录且 Windows ACL 限本人/管理员/SYSTEM。它不是完整 Auth、Storage、配置或跨 REST 请求同事务快照；不启用线上定时备份。
- 对核心 14 张业务表比较完整行哈希和数量，区分迁移本身与他人同时进行的真实业务操作。不回填客户、合同、应收、押金、收款、流水或历史审计。
- 三份迁移已应用，云端登记与本地文件已对齐为 `20261020122817`、`20261020122819`、`20261020124527`，固定 SHA256 纳入重建清单。两批迁移前后 14 表完整行哈希/数量均相同，审计仍为 7,081 条。匿名/服务角色不能执行新增读取 RPC；本批没有生产业务 DML。
- 旧公开 definer、密码保护配置和既有权限性能提醒仍作为独立专项，不为本次界面改造批量撤权或改变员工账号。

## 员工实际验收仍单独进行

黄姐需要以自己的账号查看真实审计，小颖需要以自己的账号完成实际日常操作反馈。管理员只读浏览器检查、合成角色测试及原生数据库测试不能替代她们本人使用；不通过创建真实客户收款来凑验收。

本人待办不是全公司任务中心。长租仅存在当前浏览器的未决收款号仍在原合同收款页恢复，不被此确认单列表冒充汇总。断网、结果未知时保留原操作号与证据，不重新录一笔。
