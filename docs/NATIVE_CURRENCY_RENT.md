# 原币计价长租

原币计价和“西法合同以外币支付”是两种不同业务，不能互换。

- 西法合同：原币支付仍须保存真实历史汇率，核销西法应收。
- 原币合同：`rent_currency` 与 `monthly_rent_amount` 是合同计价；租金支付 `native_settlement=true`，汇率为空，不虚构为 1。
- 原币应收保存 `amount_native`、`paid_amount_native`；流水保存 `currency`、`amount_native`。这些行的 XOF 金额槽为 0，表示未作西法估值，不是免租、未收款或汇率为 0。
- 财务、报表、驾驶舱、CSV、合同详情按币种独立展示。XOF 趋势仅含 XOF 入账，不混入未折算原币。其他西法合同的既有历史折算规则不变。
- 押金、物业费、其他费用不因租金币种改变；本次原币业务入口仅支持租金。跨币种支付、抵扣、退租结算、续签和未核账期必须先复核，不能套用西法流程。
- 新原币收款必须有明确应收服务账期，金额与所选截止日内余额完全一致；收款日不自动作为账期。合同到期后的续租不自动生成。
- 历史更正先保存合同、收款、应收、流水快照，在单事务内修改，保留原编号、收款方式未知状态及完整审计，不新增第二笔收款。

现阶段原币合同创建、续签、排期与退租不是通用多币种自助流程；错误的西法写入由数据库约束和币种检查拒绝。不能将这项租金支持描述为全币种总账或汇兑损益系统。
