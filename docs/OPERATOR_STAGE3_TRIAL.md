## 2026-09-21 当前电脑接入与审计整改

- 连接器安装于当前 Windows 用户的固定本地目录，Codex MCP 配置已指向 0.1.2；DPAPI 会话继续绑定本 Windows 用户和生产站点。
- 0.1.2 明确区分 Codex 订阅账号和 SACSI 业务身份：可共用 Chouke 的电脑/Codex，但实际录入前必须让连接器与网页切换到实际操作人的 SACSI 账号。
- 使用 Chouke 普通业务会话完成生产 `capabilities` 和 SACSI11/1002 日租订单只读查询；结果为找到订单，业务写入 0。
- 线上审计页只读检查发现 4,423 条历史记录时，操作筛选被大量重复按钮拉长、历史登录账号常显示 UUID。已在本地改为紧凑下拉筛选，使用当前用户档案补充可读姓名，并把“登录账号（系统认证）”与“业务经办人”明确分开。
- 审计页新增共用账号警示：多人共用同一 SACSI 账号时，只能追溯登录账号，不能证明当时坐在电脑前的人。
- 0.1.2 生产候选包：`work/SACSI-operator-0.1.2-candidate.zip`，SHA-256 `c26fc7d50917866ea6f1f1ecaadeabdba9857baed106422bbd1fe3fbc5a54021`。完整性、公开配置、私密环境值排除和独立 MCP 握手检查通过。

## 2026-09-16 开发交付范围

连接器 0.1.1 增加标准 stdio MCP 接入、双击登录/检查/退出、配置片段生成、中文结果和异常提示；提供独立 Windows 本地验收包和生产候选包。配置生成器不改写现有 Codex 配置；管理员仍需协助首次加入配置并重启 Codex。

只开放当前已测试的小范围业务：日租订单查询、单笔 Excel 截图收款待确认单。没有自动确认、数据库管理员密钥、任意 SQL、批量/分账/长租/出售工具。模型负责理解，工具负责实时取数与受控业务请求。
