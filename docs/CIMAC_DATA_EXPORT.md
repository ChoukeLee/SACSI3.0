# CIMAC 只读专项导出

2026-10-19开发与发布前核对记录。用户已授权推送本轮代码；生产生效仍以确切提交的部署状态核对为准，自动化测试不等同正式账号浏览器验收。

## 已确认的商铺收费口径

用户于2026-10-19确认：商铺物业费截至当时均未收取；从2027-04-01起，按900 XOF／平方米／月计费，月费以确认的计费面积乘月单价。此口径仅限商铺，不套用于仓库、公寓等其他业态。

当前将此确认作为带日期的本地参考说明，统一供财务页及两种物业费CSV使用；不是实时收款状态，也没有写入正式收费规则表。它不生成应收、欠款或收款，不将具体服务期间统一改为起算日，不覆盖后来登记的付款或已核销。收费标准起算日与每笔应收的明确账期仍是不同字段；以后以正式业务记录为准。

## 使用入口

财务页选择 **CIMAC → 收支账** 并查询后，可见流水专项 CSV 下载入口；**应收账**提供物业费应收登记导出。Excel 可直接打开含 UTF-8 BOM 的 CSV。

- **分录明细**：逐行保留登记的 XOF/CNY 金额、方向、类别、分录及收款标识、原铺位与展示铺位关联。
- **关联原币凭证**：只列所选分录关联的正式收款，每个收款 ID 一行，保留原币、登记汇率、内部凭证号、外部收据号、业务来源、冲销引用和关联分录数。
- **押金收退扣明细**：明确区分押金收取、退还和非现金扣除，核对业务类型与关联分录；不是当前押金余额或可退余额。
- **押金退款记录**：上述明细中的正式押金退款子集，不把押金扣除或其他支出当作退款。两份文件有重叠，不能相加。
- **物业费收款记录**：仅明确登记为物业费的关联收款，不按凭证前缀或备注推断；不因收过款就自动认定已覆盖某段账期。
- **物业费应收登记**：按到期日筛选当前物业费应收，包含管理、历史待核、排除及取消记录，并保留其状态；金额与账面累计已核销分列，不是历史余额或原币实际收款。

流水类下载都按**分录登记日期**筛选，不是按收款日期筛选全库；物业费应收按**到期日**筛选，并明确不是收费期间。不限当前页面。专项入口只接受项目及日期。存在楼栋、搜索、方向、类别、管理范围等其他筛选时，不提供专项下载链接；可选择仅保留项目及日期重新查看，或使用既有完整筛选导出，避免悄悄扩大范围。

退款仍按系统正金额和独立方向/业务类别保留，不擅自改号；不能把原币凭证和分录两份文件的金额相加。一个收款关联多条分录时原币只列一次，不自动分摊。没有关联收款的分录仍保留，但不推断其原币。

专项业务视图只包含有正式关联、类型与分录证据对应的付款。无付款关联的分录及非对应业务请使用完整分录导出查看；专项不把这些分录转换为原币现金。押金扣除明确标为非现金，冲销引用明确标示，不自动当成新收款或新退款。退款的业务来源ID不等于精确的原押金收据，不能据此按金额分配到某张原收据。

物业费只展示明确登记的服务起止日期。有合法日期但缺少起止另一端、依据或确认信息时保留原值并标待核，不从到期日、支付日、备注或宣传政策推定。应收已核销与收款两份表尚未逐笔核验分配关系，不可强行配平；取消和排除记录不能合计为当前欠款。无正式登记不代表免缴或未缴，空结果只有表头，不伪造一条零金额事实。

## 权限与实现边界

- GET `/api/finance/cimac-export`；`view`仅接受 `ledger`、`payments`、`deposits`、`refunds`、`property-fee-payments`、`property-fee-receivables`；另接受 `locale=zh|fr`、可选 `dateFrom/dateTo`，重复或未知参数拒绝。
- 复用 `getCurrentUser()` 和 `finance:export` 权限；仅管理员、负责人、财务可使用，并再次检查该账号能看到有效 CIMAC 项目。
- 使用用户会话 Supabase 客户端及既有 `finance_read_rpc`，不使用 service-role，不增加数据库写入口、迁移或鉴权系统。
- 固定 CIMAC 范围；辅助查询只读取已授权分录/应收关联的单元与楼栋 ID，以及分录对应收款，每批最多100个，并检查完整性与项目归属。物业费应收通过既有RPC固定 `category=property_fee, management=all` 查询，不读取全库收款。没有关联记录或引用冲突时拒绝下载，不返回半份文件。
- 不导出客户姓名、电话、自由备注、合同文件或附件。业务来源 ID 只用于内部关联，不表示重新核实了合同归属。
- CSV文本防公式注入；响应 `private, no-store`，不缓存内部财务数据。错误不包含 SQL、金额、客户资料或凭据；UTF-8响应超过4,000,000字节拒绝下载，可缩小日期范围重试。
- 以 RPC 分录/应收为主读结果，随后补查关联记录；不是跨查询的原子快照，不能称为整库备份或恢复文件。

## 不能替代的业务核对

本功能不是桌面财务原表的等价替代，也不是全库全部收款明细。原币已收但仍待折算、尚未形成正式付款/分录的历史登记，不进入上述正式流水导出；缺失不表示未收款或允许重新收款。优惠、原币退款分配、组合铺位分摊、物业费账期和收费政策仍需分别核对，不能靠汇率或金额接近猜测。

官网地图继续通过现有公开接口只读 SACSI 状态。内部凭证不会发布至官网；店名、商品、照片等授权公开内容仍在官网内容后台维护。
