# CIMAC 既有业务剥离：本地验收

## 本轮交付

建材城的首页、地图、客户、资产、合同、客户总账、流水、应收和财务分析集中在 `/cimac` 及 `/fr/cimac`。普通 SACSI 页面排除园区业务；明确指向建材城的旧项目、合同、客户和资产链接兼容转入新工作区。复用内容与原子服务，不嵌套旧页面。

客户身份仍共享，业务关系分项目。客户创建后可继续建约；财务账号保留创建资料能力，但只进入待建约交接提示，不获得签约权限。资料修改有版本检查，历史出售提供只读档案。公司级审计、全公司关联核对明确保留共享范围。

本轮没有新增数据库迁移，没有清空、重录、重算或改写生产历史账务。日租未修改，未确认收费规则仍待核。物业工单、独立交付和开业流程未在本轮实现。
