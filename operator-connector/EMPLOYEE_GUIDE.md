# SACSI 员工试用说明

这是外部 Codex 的业务连接器，不是另一套 AI，也不需要 Git、开发仓库或数据库管理员密钥。
当前只支持日租订单查询、Excel 截图中的单笔日租收款。安装包标有 `production candidate` 时尚未放行，管理员完成服务器发布核验后才能用于真实业务；`local` 包只能用于本机模拟测试。

## 共用电脑时先分清两个账号

- Codex 订阅账号负责使用 AI；临时在 Chouke 的电脑和 Codex 中工作是可以的。
- SACSI 登录账号决定业务权限和审计记录。小颖实际录入前，连接器和网页都应登录 `ying@sacsi.com`，不能因为共用 Codex 就沿用 Chouke 的 SACSI 账号。
- `check.cmd` 显示的身份不是本人时，先运行 `logout.cmd`，再由实际操作人运行 `login.cmd`。密码只由本人输入，不发送到对话中。
- 系统只能证明哪个 SACSI 账号执行了操作；多人共用同一 SACSI 账号时，不能自动证明当时坐在电脑前的人是谁。

## 第一次安装（请管理员协助一次）

1. 将完整文件夹放在固定位置，例如桌面“SACSI录入”。不要只复制几个文件。
2. 双击 `setup.cmd`，生成 `codex-mcp-config.txt`。将该文件中的配置段加入 Codex 设置的 `config.toml`，不要覆盖已有配置。已有同名 SACSI 配置时由管理员更新，不能重复粘贴。
3. 重启 Codex。在 MCP 服务器列表中确认 `sacsi_operator` 已连接；本地模拟包名称是 `sacsi_operator_local`，不能混用。
4. 双击 `login.cmd`，本人输入 SACSI 邮箱和密码。密码不会显示，不要发送到 AI 对话。双击 `check.cmd` 检查显示的本人姓名和账号标识。
5. 告诉 Codex：“使用 SACSI 工具检查我的账号，然后查询 11 栋 503 的日租订单，只查询，不入账。”楼栋房号按实际修改。

移动文件夹后必须重新生成配置并更新路径。当前安装步骤不是自动安装；无需放宽 Windows PowerShell 执行策略。

## 小颖：一次截图录入

1. 将真实 Excel 收款截图粘贴给 Codex，说明需要录入哪一笔。
2. 让它先查现有订单、客户和财务信息。没有明确金额单位、房间、日期或订单对应关系时，先问清楚。
3. 核对 Codex 给出的金额（XOF 西非法郎）、收款日期、收据号及订单。混合房租/物业、多行、长租和出售仍不在本轮范围，不让工具猜分账。
4. 它会提供待确认链接和请求号。本人打开链接，用与连接器相同的 SACSI 账号登录，核对后确认。
5. 网页明确显示完成才算入账；“待确认”不算。保留请求号供核对审计。不要重复登记同一凭证。

## 黄姐：核对审计

使用本人账号进入 SACSI 的审计日志，按录入账号、请求号或订单查找。核对实际录入人、业务经办人、金额、日期和修改前后记录；两条日志可能分别对应收款及网页确认，不代表两笔收款。若看不到日志，请管理员检查账号权限，不借用他人账号。

## 停电、断网或交接

- 未明确显示成功：保留原截图、请求号、确认链接和报错，交给管理员核查。不要换请求号重新录入。
- 确认单失效或账务变化：先重新查询，明确重做原单，沿用请求号。旧链接不能用于新金额。
- 本版本没有离线自动入账/自动补传；断网时继续保存原始凭证，恢复后核查再处理。
- 换人接手不能沿用原人的确认链接直接付款；先查原单是否已经完成，由管理员处理交接，防止重复入账。
- 共用电脑离开前双击 `logout.cmd`，网页也要退出。不同人不能共用同一个 SACSI 登录。
- `connector_busy_or_stale_lock`：勿自己删除文件，联系管理员确认是否仍有请求执行。

## 试用反馈

请记录：本人账号、操作时间、做了什么、预期结果、实际结果、请求号、报错截图。不要发送密码或访问令牌。一次真实操作顺畅并不代表所有异常场景都已验收。
