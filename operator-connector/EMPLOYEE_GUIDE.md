# SACSI 员工连接器 0.7.0 使用说明

这是外部 Codex 的业务连接器，不是另一套 AI，不需要 Git 或数据库管理员密钥。候选包须等待管理员完成服务器发布和安装包替换，才能用于真实业务。

## 使用自己的业务账号

Codex 订阅账号负责使用 AI，SACSI 账号决定权限与审计归属。共用电脑可以，录入必须使用实际操作人的 SACSI 账号。

1. 首次请管理员将完整安装包放到固定目录，运行 setup.cmd，把配置片段加入 Codex 设置，不覆盖旧配置。
2. 重启 Codex，确认 sacsi_operator 连接。本地模拟包 sacsi_operator_local 不能用于线上。
3. 本人双击 login.cmd 输入 SACSI 账号和密码，不把密码发送到 AI 对话。
4. 双击 check.cmd 确认姓名、账号标识及是否支持直接办理。不是本人先 logout.cmd 再登录。

系统只能证明登录账号，不能自动区分共用相同 SACSI 账号的两个人。离开共用设备时连接器与网页都要退出。

## 在 Codex 直接办理

管理员放行相应能力后，在 Codex 说明业务或粘贴真实截图，明确要求录入。它会自动查合同、订单和应收，只对真正缺项、歧义、冲突集中提问。资料明确且核验通过后直接提交，不再要求打开 SACSI 网页确认。0.7.0 新增 USD/CNY 长租已有应收原币收款；源码或候选包不等于已经上线。

- 截图注明币种和单位；日期、付款方式、房间或账期不清楚时补充，不默认现金或今天。
- 租金和物业费根据明确账期的实时应收及已确认单价分账。缺应收、部分已收或分账不平时停止，不为凑平金额编收费规则。
- 长租“已缴至”是租金覆盖日期，不是收到款的日期。
- USD/CNY 长租按合同原币收款，最多两位小数，不自动折算 XOF。单合同单币种，XOF 物业费另核对，不能拿美元或人民币数填进 XOF 工具。
- 原币收款只核销已有应收，不自动续约或改“已缴至”。如明确要求同步已缴至，仍需完整连续账期证据；缺失应收、币种冲突或账期不清时先核对。
- 多行截图整批办理，不逐行生成多个网页确认；冲突行不会被偷偷跳过。
- 退款登记、冲正、录错房号纠正也可在明确指令后办理，但目标、金额、日期、方式、原因等必须清楚。退款只登记实际已经退给客户的钱，不替你银行转账。
- 平台仍可能要求一次写工具授权，不要把写工具改成只读以减少弹窗。

报告“已执行并核验完成”并返回原请求号，才算本次结果已核验。“已准备”“待确认”“结果未知”“历史曾完成”不能冒充本次成功。原 Excel 与凭证保存流程继续保留。

明确要求“先看方案，不执行”时只查询/预览。旧服务器或显式使用 prepare_* 仍可能返回网页确认；直办未开放或出错时不会自动改走网页、自动重试。

## 断网、停电或交接

- 没有明确成功：保留截图、原请求号和报错，不换号重录。
- 按原号查询或恢复待办。恢复只核对，不自动重放；要继续时明确要求沿用原号执行。
- verified=false 的历史完成意味着原单不能重录，不代表已重新检查之后的全部账务。
- 内容变更先核对旧单；旧网页草稿替换引用旧确认 ID，不用新金额套旧预览。原币直办没有替换确认 ID，不换请求号重录。
- 完全断网可用 capture.cmd 保存凭证文字，截图另存；pending.cmd 查看本地原号，本地待办不代表已入账。
- 不删除 %LOCALAPPDATA%\SACSI 或损坏待办，不搬用他人会话；换电脑和回滚请管理员协助。
- 首次保存原币待办会把本人加密待办升级为 v2，原有记录全部保留。旧 0.6.0 无法读取 v2，切勿删掉待办后重录；请保留 0.7.0 按原号查回未知结果。

## 审计与反馈

本人账号进入 SACSI 审计日志，按录入账号、原请求号或订单查看。录入账号与业务经办人是两回事；同一业务的多条收款/核验日志不等于多次收款。直办使用 Codex 渠道，不冒充网页确认。

反馈提供账号、时间、业务内容、原请求号、预期/实际结果和报错截图，不提供密码或令牌。一次顺畅不代表全部业务均已验收。
